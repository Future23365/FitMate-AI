# 基础 LLM 黑盒误删恢复补全

记录时间：2026-06-05 18:27:29 CST

## 当前问题

`add-llm-basic-chat-blackbox-tests` 曾经是基础首页聊天黑盒套件的原始 OpenSpec change，但后续清理旧黑盒测试入口时被误删，导致该 change 在 OpenSpec 列表中只剩空目录和 `no-tasks` 状态。后续 `restore-manual-llm-basic-blackbox-tests` 已恢复主要手动入口和 runner，但遗漏了原 change 文档、latest report 文件和一条防止测试 fixture 泄漏进生产链路的架构扫描。

## 调整思路

原 change 文档属于审阅记录，应按删除前状态恢复；实现代码则不直接回滚到旧树，而是以当前已恢复的手动入口、当前 `/api/chat` 合同和当前测试隔离策略为准。对存在差异的地方，选择当前实现：报告时间格式继续使用当前生成器的 ISO `+08:00` 格式，默认测试仍保持不触发真实模型 API。

## 关键改动

- 恢复 `openspec/changes/add-llm-basic-chat-blackbox-tests/**` 的 proposal、design、tasks、specs 和 `.openspec.yaml`。
- 恢复 `docs/manual-llm-basic-blackbox-latest-report.md`，并把时间格式对齐到当前报告生成器。
- 恢复 `tests/agent-core/architecture-boundary.test.ts` 中基础 LLM 黑盒 fixture 不得进入生产聊天、Agent core、tools 和 renderer 的边界扫描。
- 更新 `restore-manual-llm-basic-blackbox-tests` 的 proposal、design 和 tasks，明确这次补全范围。

## 验证方式

- 运行相关普通单测，确认补回的架构扫描不会误伤当前生产链路。
- 运行两个相关 OpenSpec change 的 strict validate，确认原 change 不再是空内容。
