# 详细 LLM 测试套件

记录时间：2026-05-31 23:19:49 +0800

## 背景

原有 `npm run test:llm` 已经从内部 prompt 分支测试升级为首页聊天 3 轮黑盒流程，但它只覆盖 9 个基础冒烟场景。根目录 `LLM完整测试.md` 已经把首页能力扩展为更完整的测试清单，如果仍只保留基础套件，后续修改 AI 编排、prompt 或上下文逻辑时，很难一次性发现引用、边界、安全和输出质量类问题。

同时，真实 LLM 测试有 token 成本和外部模型依赖，不能直接塞进默认 `npm run test`。

## 调整思路

这次把测试入口分成两层：

- `npm run test`：保持原有普通 Vitest 基准测试，不请求真实模型。
- `npm run test:llm`：保留基础 9 流程 LLM 黑盒测试。
- `npm run test --detail`：显式运行详细 LLM 首页聊天黑盒套件。

详细套件仍遵循黑盒原则，只断言用户可见回复、内部字段泄漏和卡片类型，不把 trace、prompt 分支或候选分数作为通过条件。

## 关键改动

- 新增 `scripts/run-tests.mjs`，负责把 `--detail` 分流到手动 LLM runner，其余参数原样交给 Vitest。
- `manual-tests/llm/flow-fixtures.ts` 拆分为基础套件和详细套件。
- `scripts/run-manual-llm-tests.mjs` 支持 `--detail`，并为详细套件输出更高 token 预估和独立报告路径。
- 详细报告写入 `docs/manual-llm-blackbox-flow-detail-latest-report.md`，不覆盖基础报告。

## 结果

详细套件首版包含 38 个三轮流程，共 114 轮，覆盖基础回复、动作推荐、routine、plan、多轮上下文、引用修改、安全边界和输出质量。真实模型仍需显式配置 `DEEPSEEK_API_KEY` 后运行；缺 key 时会生成跳过报告，避免静默 mock。
