统计范围：只覆盖本次报告中第 1 轮失败的基础 flow，不把首轮失败导致的 skipped turn 计为独立问题。

  - 现象：居家背部 30 分钟、胸部 20 分钟无器械、循环胸部训练这类条件已基本明确的请求，返回了安全错误或只给动作列表。
