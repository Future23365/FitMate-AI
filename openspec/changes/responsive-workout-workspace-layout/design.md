## Context

当前项目面向 PC 端使用，但 `app/globals.css` 中 `sm/md/lg/xl` 均为 `0px`，导致页面里的 `md:*`、`lg:*`、`xl:*` 实际长期生效。动作编排页和训练计划页又分别使用全局左侧栏加页面右侧栏的结构，在普通桌面窗口下会长期占用约 `560px` 到 `580px` 横向空间。

这次问题不是单个卡片样式拥挤，而是工作区布局优先级不清：左侧导航、右侧辅助信息和主任务区同时常驻，导致动作编排工作台和训练月历没有稳定的优先宽度。

## Goals / Non-Goals

**Goals:**

- 建立 PC 端桌面宽度分层：宽桌面允许三列常驻，普通桌面优先主内容，窄窗口让辅助信息按需浮出。
- 为全局侧边栏提供展开态和收缩态，释放动作编排页与训练计划页的主内容宽度。
- 将动作编排页右侧“动作库 / 已保存编排”改造成工作区素材面板，可常驻也可按需打开。
- 将训练计划页右侧“当天计划 / 已保存编排”改造成日期详情面板，可常驻也可按需打开。
- 复用公共右侧抽屉的 portal、遮罩、滚动锁定和关闭行为，减少重复外壳。

**Non-Goals:**

- 不做手机端适配，不重新引入移动端主导航策略。
- 不重做训练执行页的一屏训练布局。
- 不改变训练计划、动作编排、训练安排的数据模型、API 或持久化契约。
- 不调整 AI 编排、训练生成规则或训练执行状态机。
- 不重做项目整体视觉风格，继续沿用浅色 Material Design 3 风格。

## Decisions

1. 恢复有意义的桌面断点，但保持 PC-only 产品边界。
   - 原因：`xl=0px` 让三列布局在所有宽度下生效，无法表达“足够宽才常驻右栏”。
   - 方案：保留移动端非目标的策略，但给桌面布局提供可用断点，例如普通桌面、宽桌面、超宽桌面。
   - 取舍：需要审查现有 `md/lg/xl` class 是否依赖旧的 `0px` 行为；本 change 应重点覆盖主应用 shell、动作编排页、训练计划页和训练执行页回归。

2. 左侧导航采用全局两态，而不是在每个页面单独隐藏。
   - 原因：左侧栏是全局 shell 能力，页面不应该各自处理导航宽度。
   - 方案：展开态保留现有 `260px` 信息密度；收缩态保留图标导航、新建入口和设置入口，隐藏历史列表与文字。
   - 取舍：收缩态会降低历史对话扫读能力，但能稳定释放主工作区宽度；历史列表仍可在展开态使用。

3. 右侧栏改为“可停靠辅助面板”，不只做窄版固定栏。
   - 原因：动作库、已保存编排和日期详情是按需辅助任务，不应该在普通桌面长期挤压主任务区。
   - 方案：宽桌面下右侧面板可常驻；普通桌面下以右侧 drawer/overlay 方式打开；窄窗口下只保留明确入口按钮或轻量 rail。
   - 备选：把右侧栏压缩为 `56px` 图标 rail。放弃原因是动作库和日期详情内容无法在 rail 中可用，仍需要浮出面板。

4. 动作编排页以“当前编排工作台”为主任务。
   - 原因：用户在该页的核心操作是查看、排序、调整热身/训练/拉伸动作；动作库和已保存编排是素材来源。
   - 方案：主编排区保持可读宽度；右侧素材面板在宽屏常驻，在普通桌面由 `动作库` / `已保存` 入口打开。
   - 取舍：普通桌面下添加动作多一步打开面板，但动作行编辑控件不会被持续挤压。

5. 训练计划页以“月历”为主任务。
   - 原因：训练计划页的核心是扫读月份、选择日期和查看当天安排；右侧详情不能长期牺牲月历宽度。
   - 方案：月历保持主内容优先；日期详情在宽屏常驻，在普通桌面通过选中日期后的详情面板打开；本月统计和最近动态作为次级内容收敛。
   - 取舍：普通桌面下详情查看会多一步或以浮层出现，但月历主体稳定。

6. 公共右侧抽屉扩展为工作区辅助面板外壳。
   - 原因：项目已有 `shared-right-drawer`，应复用 portal、遮罩、ESC、滚动锁定和 `drawer-open` 联动。
   - 方案：公共组件支持标题、入口来源、宽度、停靠/浮出模式和内部 tab；业务页只负责内容和状态。
   - 取舍：公共组件需要避免过度参数化，业务内容仍留在页面或领域组件中。

## Risks / Trade-offs

- [Risk] 恢复断点后影响旧页面布局 → 先盘点 `md/lg/xl/2xl` 使用点，重点验证主应用 shell、动作编排页、训练计划页和训练执行页。
- [Risk] 左侧栏收缩态增加全局状态复杂度 → 只保存展开/收缩偏好，不把页面级右侧面板状态混入全局 sidebar 状态。
- [Risk] 右侧辅助面板浮出后遮挡主内容 → 使用明确入口、关闭按钮、ESC/遮罩关闭和背景滚动锁定；面板打开时不改变主内容数据状态。
- [Risk] 动作编排页添加动作频率高，drawer 模式可能增加操作成本 → 宽屏仍常驻；普通桌面下保持添加后面板不自动关闭，支持连续添加。
- [Risk] 训练计划页选中日期后详情不够明显 → 月历顶部或右上角提供当前选中日期详情入口，并在选中日期后自动打开或高亮入口。

## Migration Plan

1. 调整全局桌面断点和 sidebar 宽度 token，新增或整理工作区布局工具类。
2. 为 `AppSidebar` 增加展开/收缩态，保持导航、设置和新建入口可达。
3. 扩展公共右侧抽屉或新增基于它的工作区辅助面板外壳。
4. 迁移动作编排页右侧动作库/已保存编排为可停靠素材面板。
5. 迁移训练计划页右侧当天计划/已保存编排为可停靠日期详情面板。
6. 对 `/training` 做静态回归，确认全局断点调整没有破坏其一屏训练布局。
7. 运行 `npm run lint`、`npm run typecheck`、`npm test`，并按需运行 `npm run build`。
