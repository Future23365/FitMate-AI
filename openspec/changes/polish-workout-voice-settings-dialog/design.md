## Context

`/training` 的语音设置弹窗目前集中承载 voice 选择、语音参数、自检和浏览器 API 版本说明。用户现在希望这层弹窗更符合真实使用优先级：中文 voice 要更容易选到，弹窗出现时主页面要有向后缩的空间反馈，自检失败时要给出可执行恢复建议，浏览器版本信息要通过彩色图标提高可读性。

## Goals / Non-Goals

**Goals:**
- 优先展示 `zh-CN` voice，其次其他中文 voice，再展示非中文 voice。
- 弹窗打开和关闭时提供轻量动效，并让主训练页面出现向后缩的视觉层级。
- 当自检失败但运行时 API 已支持时，给用户明确的“尝试重启浏览器后再检测”建议。
- API 版本区域为 Chrome、Edge、Firefox、Safari、iOS Safari 提供彩色图标和版本信息。

**Non-Goals:**
- 不改变训练流程、计时、自动推进、语音播报开关语义。
- 不新增服务端 API、数据库字段或跨设备同步。
- 不引入外部图标依赖；浏览器图标优先用本地 CSS / 简单 inline SVG / 现有图标能力实现。

## Decisions

1. voice 排序在 UI 层按语言优先级稳定排序。
   - `zh-CN` voice 权重最高，其他 `zh-*` 或名称包含中文特征的 voice 次之，非中文 voice 保持原始顺序。
   - 原因：浏览器 voice 列表来自运行时，排序只影响选择展示，不应改变底层可用性检测。

2. 主页面向后缩效果由训练页根容器状态控制。
   - 弹窗打开时对主训练内容应用 `scale`、轻微位移、圆角/阴影/遮罩层级变化；关闭时恢复。
   - 原因：效果需要作用于主页面，而不是只在弹窗内部做进入动画。

3. 自检失败建议基于运行时 API 支持状态显示。
   - 若 Web Speech 或 Web Audio API 不存在，则展示“不支持”类提示。
   - 若 API 存在但检测失败、阻止或超时，则展示“可尝试重启浏览器后再检测”的恢复建议。
   - 原因：重启浏览器只对运行时卡住、voice 服务异常或浏览器音频状态异常有意义。

4. 浏览器彩色图标使用可维护的本地组件。
   - 优先创建小型 `BrowserIcon` 映射，使用 CSS 色块或简洁 SVG 表达 Chrome、Edge、Firefox、Safari、iOS Safari。
   - 原因：避免新增依赖，也避免把浏览器 logo 资产散落到 public。

## Risks / Trade-offs

- [Risk] 浏览器 logo 近似图标可能与官方品牌图形不完全一致 → 使用简洁识别图标和文字标签共同表达，避免只依赖图形。
- [Risk] 主页面缩放可能导致固定定位或抽屉层级冲突 → 弹窗打开时只作用于训练页主容器，并确保弹窗层级高于动作详情抽屉。
- [Risk] voice 列表很长时排序后用户找英文 voice 需要滚动 → 保留所有 voice，且只调整顺序不隐藏非中文 voice。
- [Risk] 自检失败建议可能被误解为一定能修复 → 文案使用“可以尝试”，并保留具体失败步骤。
