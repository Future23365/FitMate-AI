## Context

训练日历页当前以月历为主体，右侧栏负责展示选中日期的训练安排和操作。已保存计划已经从常驻横向列表改为顶部工具栏中的按需入口，但当前悬浮下拉仍会覆盖月历内容，并且入口位置与“给当前日期排期”的任务上下文不一致。

## Goals / Non-Goals

**Goals:**

- 将已保存计划入口移动到右侧选中日期详情栏，使入口和排期目标保持在同一上下文。
- 用右侧栏内部的选择模式替代悬浮下拉，降低月历背景和列表内容的视觉冲突。
- 保留选择计划后安排到当前选中日期的能力，并在完成后回到日期详情。

**Non-Goals:**

- 不调整移动端适配。
- 不改变 `WorkoutRoutine`、`WorkoutSchedule` 或相关 API 契约。
- 不新增搜索、筛选、分类或批量排期能力。

## Decisions

1. 已保存计划入口放入右侧日期详情栏。
   - 原因：用户的真实任务是“给当前选中日期添加训练”，入口应该出现在该日期详情和操作区域内。
   - 备选方案：保留顶部按钮并让右侧栏切换。放弃原因是入口和结果区域不在同一视觉区域，交互因果关系不清晰。

2. 使用右侧栏模式切换，不使用弹层。
   - 原因：计划列表属于排期任务的工作内容，不是轻量菜单项；放在固定面板中能减少覆盖、阴影和背景干扰。
   - 备选方案：美化悬浮下拉并增加背景遮罩。放弃原因是仍然需要处理浮层与月历内容的层级竞争。

3. 计划列表采用紧凑列表行。
   - 原因：右侧栏宽度有限，列表行比卡片堆叠更适合快速扫描和添加。
   - 备选方案：保留当前卡片式菜单项。放弃原因是多层卡片、边框和阴影会继续增加视觉噪音。

## Risks / Trade-offs

- [Risk] 顶部工具栏移除入口后，用户可能不立即发现已保存计划入口。→ 在右侧日期详情的主要操作区使用清晰的“从已保存计划添加”按钮，并保留计划数量提示。
- [Risk] 右侧栏选择模式可能遮住当天已有安排。→ 提供“返回当天安排”操作，选择计划后自动回到日期详情。
